# sns-creative — 홍보물 세트 만들기

처음 홍보물 세트를 만든 순서를 그대로 옮긴 것이다. 같은 순서로 다시 만들면 대상과 목적만 바꿔 일관된 결과가 나온다.

## 입력

| 입력 | 어디서 |
| --- | --- |
| 브랜드 규칙 | `brand.md` (색, 글꼴, 말투, 꼭 넣을 것, 쓰면 안 되는 표현) |
| 서비스 내용 | `기획서.md` (대상, 문제, 해결, 핵심 기능) |
| 서비스 주소 | `brand.md`의 주소. QR은 `qr.png` |
| 사용 장면 | `screenshot.png` (390×844). 없거나 화면이 바뀌었으면 다시 찍는다 |
| 이번 홍보의 대상과 목적 | 사용자가 준다. 예: `대상: 1학년 신입생, 목적: 점심 밥약 알리기`. 없으면 한 번 묻는다 |

## 출력

`creatives/날짜/` 폴더(예: `creatives/2026-11-12/`)에 만든다. 날짜 폴더를 쓰는 이유는 이전 홍보물을 덮어쓰지 않기 위해서다.

- `카드뉴스/01.png`~`06.png` (1080×1350)과 원본 HTML
- `caption.md`: 캡션 3안, 해시태그 10개
- `shortform.md`: 30초 숏폼 대본 (장면, 화면, 자막, 대사)
- `story.png` (1080×1920)과 원본 HTML
- `index.html`: 전체를 한눈에 보는 미리보기

## 순서

### 1. 금지 표현 검사 (만들기 전에)

`brand.md`의 '쓰면 안 되는 표현'을 읽고, 쓸 문구 초안을 먼저 적은 뒤 검사한다. 걸리는 문장은 고친 다음에 디자인으로 넘어간다. 이미지로 만든 뒤에는 고치기가 번거롭기 때문이다.

- 과장·보장("100%", "무조건", "절대 안전"), 진단·치료 효과, 다른 서비스 깎아내리기, 만남·연애 암시
- 출처 없는 숫자와 통계. 숫자가 필요하면 `사실확인.md`에 출처가 있는 것만 쓴다
- 화면 캡처 속 방은 가상 데이터다. 실제 식당이나 실제 이용자처럼 쓰지 않는다

### 2. 생성

카드뉴스 6장의 구성은 **질문 → 문제 → 해결 → 사용 장면 → 차별점 → 행동 유도**다.

- 각 장은 1080×1350 크기의 HTML 한 장으로 만든다. 공통 스타일은 `card.css` 하나에 둔다
- 제목은 15자, 본문은 40자 안쪽
- 4번 장에는 `screenshot.png`를, 6번 장에는 서비스 주소와 `qr.png`를 넣는다
- 모든 장에 '혼밥 탈출'과 '수업용 시제품'을 작게 넣는다
- 색은 `brand.md`의 세 가지만 쓰고 강조색은 토마토 하나다. 글꼴은 제목 Paperlogy, 본문 IBM Plex Sans KR
- 한글은 `word-break: keep-all`, 제목 행간 1.3, 본문 행간 1.6

PNG로 찍는 명령 (프로젝트 폴더에서 실행):

```bash
node tools/shot.mjs creatives/날짜/카드뉴스/01.html creatives/날짜/카드뉴스/01.png 1080 1350
```

```bash
node tools/shot.mjs creatives/날짜/story.html creatives/날짜/story.png 1080 1920
```

`tools/shot.mjs`는 글꼴을 다 불러온 뒤에 찍는다. 처음 쓰는 컴퓨터에서는 `tools` 폴더에서 `npm install`을 한 번 한다.

캡션은 말투가 서로 다른 3안으로 쓰고, 해시태그는 정확히 10개를 단다. 숏폼 대본은 30초 분량의 표로 쓴다.

### 3. 맞춤법 검사

카드 문구, 캡션, 대본의 맞춤법과 띄어쓰기를 본다. 이미지에 들어간 글자는 찍은 PNG를 열어 직접 읽어서 확인한다. 글자가 잘리거나 겹치지 않았는지, 글꼴이 제대로 나왔는지도 이때 본다.

### 4. 미리보기를 보여 주고 승인 받기

`index.html`을 열어 사용자에게 보여 준다. 무엇을 만들었는지와 확인하지 못한 것을 함께 알린다. 사용자가 승인하기 전에는 SNS에 올리거나 외부로 보내지 않는다.

고쳐 달라는 요청은 한 번에 하나씩 반영하고, 고친 장만 다시 찍는다.

## 다시 만들 때

```text
/sns-creative 대상: [1학년 신입생], 목적: [점심시간 밥약 방 알리기]
```

대상과 목적에 맞춰 1번 장의 질문과 6번 장의 행동 유도를 바꾼다. 문제·해결·차별점은 `기획서.md`에서 벗어나지 않는다.
