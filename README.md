# 혼밥 탈출

- 혼자 밥 먹기 외로운 사람이 "언제·어디서·무엇을" 먹을지 정한 밥약 방에 버튼 한 번으로 참여하는 서비스입니다.
- 방을 열면 다른 사람이 참여하고, 방 안 채팅으로 만날 곳과 시간을 실시간으로 조율합니다.
- 1:1이 아니라 2~4명 그룹으로 만나고, 공개된 식당에서만 만나도록 안내합니다.

**수업용 시제품입니다.** 삼육보건대학교 AI 앙트레프레너 LAUNCH!(2026-11-12)에서 9조 CODE NEXUS / 야르가 만들었습니다. 목록의 '가상 사용자' 방은 예시 데이터이며 실제 사람이나 식당이 아닙니다.
